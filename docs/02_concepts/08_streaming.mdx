Certain resources, such as key-value store records and logs, support streaming directly from the Apify API. You can then process large resources incrementally without downloading them entirely into memory, which suits large or continuously updated data.

Supported streaming methods:

- <ApiLink to="class/LogClient#stream">`LogClient.stream()`</ApiLink> - Stream a log in real time. Resolves to a Node.js `Readable`, or `undefined` when the log doesn't exist.
- <ApiLink to="class/KeyValueStoreClient#getRecord">`KeyValueStoreClient.getRecord()`</ApiLink> with the `stream: true` option - Stream a key-value store record as raw data. Resolves to a record whose `value` is a Node.js `Readable`, or `undefined` when the record doesn't exist.
- <ApiLink to="class/RunClient#getStreamedLog">`RunClient.getStreamedLog()`</ApiLink> - Redirect the log of a run to a logger while the run is in progress. For details, see [Redirecting Actor run logs](./05_logging.mdx#redirecting-actor-run-logs).

A stream holds its connection open until you consume it to the end or destroy it. Iterating it with `for await` or passing it to `pipeline()` from `node:stream/promises` does either one for you, including when the processing throws.
